iconicpink-blue · live demo

Simulation in your browser · the game itself is not here

PC keys (keyboard & mouse) in place of the Xbox buttons in GTA VI's prompts. Press real keys and click: the icons react the way the game's prompt code makes them react. The real in-game test needs your own copy of the game; the Windows test is recorded here.

1 · Press any key

Click the scene, then try WASD, Shift, Space, F, R, Q, C, V, Tab, Ctrl, the arrows, the mouse buttons and the wheel, or move the mouse. Pressed icons shrink to 0.8 and switch to the pressed colours, as in the game.

2 · Prompt types

The game draws, animates and tints the icons itself; only their drawing changes. Values from the game's prompt code: pressed scale 0.8, colour change over 6 frames, completion glow at 50%, QTE track at 15%.

3 · The cursor

This whole page is already using it. In Windows, the launcher swaps the cursor only while the game window has focus, and puts the normal one back when you leave.
